# SmartCivi system diagrams

Proposal title: SmartCivi Civil Registry Request and Appointment Management System

The PDF contains the project identification, selection explanations, data blueprinting response, all 17 diagram types listed in the assignment, and implementation notes. The DFD has two views, so there are 18 diagram figures.

Core exercise selections: 01 System Architecture, 10 Use Case, and 12 Sequence.

PNG images are ready to insert into Word or slides. SVG files preserve editable vector shapes and text; open them in a vector editor or compatible diagram tool. A PDF reader can search and select the PDF text. manifest.json describes each figure.

The Profile Diagram is optional proposed UML vocabulary. Object values are fictional. Timing is logical ordering, not a benchmark. Requirements use SysML notation. Read the PDF implementation notes before presenting appointment, attachment or payment features as completed.
